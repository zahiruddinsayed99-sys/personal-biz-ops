# Purpose

This document defines the standard GitHub Issue templates used throughout BusinessHub AI.

Every issue should be small, independently testable, traceable to a sprint, and suitable for a single focused AI implementation session.

---

# General Rules

- One issue = one engineering objective
- Link every issue to exactly one Sprint Milestone
- Assign appropriate labels before implementation
- Include clear acceptance criteria
- Update issue status throughout execution
