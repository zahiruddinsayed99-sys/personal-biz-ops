# Daily Execution Workflow

1. Open current sprint.
2. Select the first Ready issue.
3. Create or switch to the sprint branch.
4. Complete implementation.
5. Run automated tests.
6. Commit using Conventional Commits.
7. Open Pull Request.
8. Move the issue to Completed.
9. Continue with the next Ready issue.
