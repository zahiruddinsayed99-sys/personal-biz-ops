### I. Complete Application Screen Flow

**Public / Unauthenticated Zone**

* **✅ `/onboard` (Implemented):** `TenantOnboardingComponent`. Creates the initial organization and admin user. Routes to `/login` upon success.


* **🚧 `/login` (Missing):** User authentication. Captures the `access_token` and routes to the main app shell.


* **🚧 `/invite/accept` (Missing):** Invited team members land here via email link, set their password, and consume the token. Routes to `/login`.



**Secure Zone (Wrapped in Missing App Shell Layout)**

* **🚧 `/settings` (Missing):** Admin dashboard to manage the 15-character GSTIN tax ID and generate team invitation links.


* **✅ `/billing` (Implemented):** `BillingDashboardComponent`. Redirects to Stripe for INR-locked checkout. *(Needs: Stripe Customer Portal button).*


* **✅ `/crm` (Implemented):** `CrmPipelineComponent`. Kanban board to manage active deals. *(Needs: Connect AI scoring buttons).*


* **🚧 `/crm/contacts` (Missing):** CRUD data table for standard customer management.
* **✅ `/ai` (Implemented):** `AiDashboardComponent`. Uploads markdown documents to the RAG index.


* **✅ `/lms-author` (Implemented):** `LmsAuthorComponent`. Creates course modules and lessons. *(Needs: Rich text/Markdown editor integration).*


* **✅ `/lms-learner` (Implemented):** `LmsLearnerComponent`. Self-enrollment and progress tracking. *(Needs: Quiz assessment UI).*

### II. GitHub Milestones & Issues

#### Milestone 0: Core Foundation (Baseline - Completed)

* **Issue 0.1: Self-Service Tenant Onboarding:** Created `TenantOnboardingComponent` mapping to `POST /auth/onboard`.


* **Issue 0.2: Feature Components Skeleton:** Scaffolding complete for CRM, AI, LMS, and Billing modules.

#### Milestone 1: App Shell & Identity

* **Issue 1.1: Implement `/login` Component**
* **Description:** Build login form (email/password) mapping to `POST /api/v1/auth/login`.


* **Acceptance Criteria:** Must save `access_token` to `localStorage` and route user into `/crm`.


* **Issue 1.2: Implement `/invite/accept` Component**
* **Description:** Build registration form for invited members mapping to `POST /api/v1/auth/invite/accept`.


* **Acceptance Criteria:** Parse token from URL, accept new password, and route to `/login` upon 200 OK.


* **Issue 1.3: Build Global App Shell & Navigation**
* **Description:** Create a master layout component with a persistent sidebar (routing to CRM, AI, LMS, Billing, Settings) and top navbar.
* **Acceptance Criteria:** Must include a logout button mapping to `POST /api/v1/auth/logout`.



#### Milestone 2: Workspace Setup & Billing Guards

* **Issue 2.1: Workspace Settings UI (`/settings`)**
* **Description:** Admin interface to manage organization profile via `PATCH /api/v1/organizations/me`.


* **Acceptance Criteria:** Form must validate Indian GSTIN format (15 characters) and billing state.




* **Issue 2.2: Team Invitation UI (Inside `/settings`)**
* **Description:** Interface for admins to generate secure invite links via `POST /api/v1/organizations/invitations`.


* **Acceptance Criteria:** Must display the plaintext token link for copying.




* **Issue 2.3: Global Overage Interceptor & Portal**
* **Description:** Protect app from free-tier limits. Add Customer Portal button to `billing-dashboard`.


* **Acceptance Criteria:** If any API returns HTTP `402` (`ERR_BILLING_001`), the UI must display a global warning modal and redirect to `/billing`.





#### Milestone 3: CRM Expansion & AI Wiring

* **Issue 3.1: Contacts Management UI (`/crm/contacts`)**
* **Description:** Build a data table and creation modal for `/api/v1/crm/contacts`.


* **Issue 3.2: Wire CRM Deals to AI Endpoints**
* **Description:** Update existing `CrmPipelineComponent` to include action buttons on deal cards.
* **Acceptance Criteria:** "Score Deal" button must trigger `POST /api/v1/crm/deals/{id}/ai-score`.





#### Milestone 4: LMS Completion

* **Issue 4.1: Wire LMS Quiz Generation**
* **Description:** Add "Generate Quiz" button to the existing `LmsAuthorComponent`.
* **Acceptance Criteria:** Must map to `POST /api/v1/lms/quizzes/generate`.




* **Issue 4.2: Build Learner Quiz Player (`/lms-learner`)**
* **Description:** Create UI for students to submit quiz answers via `POST /api/v1/lms/quizzes/attempts`.


* **Acceptance Criteria:** UI must display a clear Pass/Fail result based strictly on the 80% minimum score threshold (`BR-LMS-001`).
