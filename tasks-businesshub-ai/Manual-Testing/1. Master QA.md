# Master QA Test Plan: V1 Release

## Test Environment Setup

1. Start backend server (API) and database.
2. Start frontend server: `npm start`.
3. Open browser to `http://localhost:4200`.
4. Open browser dev tools (F12) to watch Network tab.

## User Roles Dictionary

| Role | Access Level |
| --- | --- |
| **`SUPER_ADMIN`** | Platform owner. Has access to hidden `/admin/tenant`. |
| **`TENANT_OWNER`** | Company boss. Access to everything in their workspace. |
| **`DOMAIN_MEMBER`** | Normal worker. No access to Settings, Billing, or Course Authoring. |

---

## Scenario 1: Platform & Tenant Setup (Super Admin)

*Goal: Test hidden tools and locked public gates.*

### 1.1 Secure Public Onboard

* **Role:** Anonymous (No login)
* **Action:** Go to `http://localhost:4200/onboard`.
* **Expect:** Form is hidden. See "Signup is invite-only" message.
* **Action:** Go to `http://localhost:4200/onboard?code=SECRET123`.
* **Expect:** Registration form shows up.

### 1.2 Super Admin Tenant Creation

* **Role:** Log in as `SUPER_ADMIN`
* **Action:** Look at side menu. Click "Tenant Manager" (`/admin/tenant`).
* **Action:** Type "QA Corp" and slug "qa-corp". Click create.
* **Expect:** Success toast. Network tab shows `200 OK` for `POST /api/v1/tenant/onboard`.
* **Action:** Click Logout. Expect route to `/login`.

## Scenario 2: Company Setup & Admin Tools (Tenant Owner)

*Goal: Test tax rules, team invites, and billing locks.*

### 2.1 Workspace & GSTIN Validation

* **Role:** Log in as `TENANT_OWNER`
* **Action:** Click "Settings" in side menu.
* **Action:** Type bad GSTIN (e.g., "123"). Click Save.
* **Expect:** Form shows error. Button blocked.
* **Action:** Type exactly 15 chars (e.g., `12ABCDE3456F7Z8`). Select State. Click Save.
* **Expect:** Success toast. Data saves to backend.

### 2.2 Invite Team Member

* **Role:** `TENANT_OWNER` (Still in Settings)
* **Action:** Scroll to Team Invite. Type `worker@test.com`. Click "Create Invite".
* **Expect:** App shows full URL with token on screen. Copy button works.

### 2.3 Accept Invite & Login Loop

* **Role:** Anonymous (Open new Incognito window)
* **Action:** Paste the invite URL from step 2.2.
* **Expect:** See Invite Accept form (`/invite/accept`).
* **Action:** Type name and password. Click save.
* **Expect:** App routes to `/login`.
* **Action:** Log in with `worker@test.com` and new password.
* **Expect:** Login works. App routes to `/crm`.

### 2.4 Billing & Overage Interceptor

* **Role:** `TENANT_OWNER`
* **Action:** Force an API limit (QA must trigger 0 credits on backend).
* **Action:** Click "AI Score" on a CRM deal.
* **Expect:** Screen blocks action. Big warning shows: "Workspace locked". App forces route to `/billing`.
* **Action:** Click "Manage Billing (Portal)".
* **Expect:** Network hits `POST /api/v1/billing/portal` and redirects to Stripe.

## Scenario 3: Daily Work & LMS (Domain Member)

*Goal: Test standard worker limits and core features.*

### 3.1 Security & RBAC Checks

* **Role:** Log in as `DOMAIN_MEMBER` (The worker created in 2.3)
* **Action:** Look at side menu.
* **Expect:** "Settings", "Billing", "LMS Author", and "Tenant Manager" are missing.
* **Action:** Type `http://localhost:4200/settings` in URL bar and hit enter.
* **Expect:** Route blocked. App kicks user back to `/crm`.

### 3.2 CRM & Contacts

* **Role:** `DOMAIN_MEMBER`
* **Action:** Go to CRM. Click "Contacts" tab.
* **Action:** Click "Add Contact". Fill form. Save.
* **Expect:** New contact shows in table.

### 3.3 LMS Learner & 80% Rule

* **Role:** `DOMAIN_MEMBER`
* **Action:** Go to "LMS Learner". Enroll in course. Read lesson.
* **Action:** Click "Take Quiz". Pick wrong answers (score under 80). Submit.
* **Expect:** See red "FAIL" message.
* **Action:** Take quiz again. Pick correct answers (score 80 or higher). Submit.
* **Expect:** See green "PASS" message.

## Scenario 4: LMS Authoring (Admin/Manager)

*Goal: Test Markdown and AI Quiz generation.*

### 4.1 Course & AI Quiz Creation

* **Role:** Log in as `TENANT_OWNER`
* **Action:** Go to "LMS Author". Create Course > Module > Lesson.
* **Action:** Type Markdown text in editor. Save.
* **Action:** Click "Generate AI Quiz".
* **Expect:** Progress bar shows polling. After wait, 5 questions appear on screen.
