### Local Verification & Testing Guide: Module 4 — LMS Engine

## 1. Database Migrations

**1. Navigate to the backend directory and set up the environment**

```bash
cd backend
source venv/bin/activate
export DATABASE_URL="postgresql+asyncpg://postgres:postgres@localhost:5432/app-db"

```

**2. Apply the database migrations**
*(Creates the new LMS schema: courses, course_modules, lessons, course_enrollments, lesson_progress, quizzes, quiz_questions, quiz_answers, quiz_attempts, quiz_responses)*

```bash
alembic upgrade head

```

**3. (Optional) Verify reversibility**

```bash
alembic downgrade -1
alembic upgrade head

```

**4. Run the automated migration test to confirm success**

```bash
export PYTHONPATH=.
python -m pytest tests/test_database_migrations.py -v

```

## 3. API Functional Testing (Manual Scenarios)

*Using tools like curl or Postman (and authenticating via the `/api/v1/auth/login` endpoint to obtain JWTs):*

**A. Authoring & RBAC / Tenant Isolation:**

* **Success:** Authenticate as a `TENANT_OWNER` or `LMS_MANAGER` for "Tenant A". Call `POST /api/v1/lms/courses` to create a draft course.
* **RBAC Block:** Authenticate as a `DOMAIN_MEMBER`. Call the same endpoint and ensure it returns HTTP `403 Forbidden` (`ERR_RBAC_001`).
* **Tenant Isolation:** As "Tenant B", attempt to call `GET /api/v1/lms/courses/{course_id_from_tenant_a}`. Ensure it securely returns HTTP `404 Not Found`.

**B. Learner Enrollment & Progress:**

* **Enroll:** Authenticate as a `DOMAIN_MEMBER`. Call `POST /api/v1/lms/enrollments` with the valid `course_id`.
* **Progress:** Call `POST /api/v1/lms/lessons/{lesson_id}/progress` with `{"is_completed": true}`.
* **Completion:** Once the final required lesson in a course is completed via the endpoint, verify the corresponding `CourseEnrollment` record automatically transitions its status to `COMPLETED`.

**C. Quiz Scoring System:**

* **Setup:** Retrieve a valid `quiz_id`. Call `POST /api/v1/lms/quizzes/attempts` with the selected answer IDs mapping (e.g., `{"responses": {"question_id": "answer_id"}}`).
* **Pass Verification:** Provide answers that score >= 80%. Confirm the API response returns `{"score": X, "passed": true}`.
* **Fail Verification:** Provide incorrect answers < 80%. Confirm the API returns `{"score": Y, "passed": false}`.

**D. AI Quiz Generation & Credit Metering:**

* **Generation:** Authenticate as a `TENANT_OWNER` belonging to an organization with > 10 AI credits. Call `POST /api/v1/lms/quizzes/generate` with `{"lesson_id": "..."}`. Verify it returns HTTP `202 Accepted` with a `job_id`.
* **Verify Celery Output:** Observe the Celery worker logs. It should parse the markdown, ping the `AiGatewayService`, and persist the questions/answers to the database.
* **Billing Guard:** Reduce the tenant's AI credits to 0 (or FREE tier overage). Attempt the same API call. It must immediately return HTTP `402 Payment Required` (`ERR_BILLING_001`) without dispatching the background worker.

## 5. Frontend UI Verification

**1. Navigate to the frontend directory and install dependencies**

```bash
cd frontend
npm install

```

**2. Run the Angular Unit Tests**

```bash
npx ng test --watch=false --browsers=ChromeHeadless

```

> **Expected Result:** 4/4 passing tests.

**3. Verify the Angular Build**

```bash
npx ng build

```

> **Expected Result:** Clean compilation with zero errors.

**4. Run the local development server**

```bash
npx ng serve

```

**5. View Dashboards**

* **Learner View:** Navigate to `http://localhost:4200/lms-learner`. Verify the display of active enrollments, course progression meters, and the markdown lesson player UI.
* **Author View:** Navigate to `http://localhost:4200/lms-author`. Enter a mock `lesson_id` and click **Generate AI Quiz**.

> **Note on Polling:** The local author UI demonstrates real-time RxJS polling by requesting a simulated Celery job ID and dynamically updating the progress bar until resolution. Actual end-to-end integration is verified securely via the backend tests.
