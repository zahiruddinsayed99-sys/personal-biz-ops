I reviewed the proposed **Module 4: LMS Engine** scope in the context of the overall **Business Hub Fullstack** architecture, with CRM remaining the major/core module.

I agree that the LMS scope aligns well with the Business Hub vision, provided we position it as an **AI-powered Learning & Enablement module**, rather than as a standalone generic LMS.

I am happy to finalize the scope with the following additions/clarifications:

### Confirmed LMS Scope

* Course Builder with **Course → Module → Lesson** hierarchy
* Draft → Published workflow
* Rich-text lesson content and external video links
* RBAC enforcement through `lms:write`
* AI Quiz Generator using the existing **AI Platform, AI Gateway, Celery workers, and credit metering**
* Structured AI quiz JSON using `lms_quiz_v1`
* Async quiz generation with job-status tracking
* AI Credit deduction and graceful insufficient-credit handling
* Course enrollment
* Lesson-level progress tracking
* Quiz execution with immediate feedback and explanations
* **Quiz Attempts** persistence
* **Course Completion** state (`NOT_STARTED`, `IN_PROGRESS`, `COMPLETED`)
* Basic **Course Metadata** such as title, description, category, difficulty, duration, etc.
* Billing/Tier limits using the existing Billing Engine and platform soft-lock mechanism
* Strict tenant isolation using `organization_id`

### Architectural Direction

The LMS should reuse existing Business Hub platform capabilities rather than introduce separate infrastructure:

* Existing RBAC
* Existing tenant isolation
* Existing Billing/Credit system
* Existing AI Gateway
* Existing Celery infrastructure
* Existing asynchronous job-status pattern

CRM integration should be **supported architecturally but not overbuilt in this MVP**. The LMS should remain loosely coupled so that future employee/customer enablement scenarios can connect naturally with CRM.

### Explicitly Out of Scope for This Release

To keep the project on schedule, I do not want to expand the current scope with:

* Certificates
* Gamification
* Discussion/forums
* SCORM
* Live classes
* Advanced learning analytics
* Full customer-training workflows

With these clarifications, I consider the **Module 4 LMS Engine functional scope finalized** and ready for the next planning step: database schema definition, API boundaries, and GitHub issue breakdown.

Please incorporate these points into the master plan without further scope expansion.
