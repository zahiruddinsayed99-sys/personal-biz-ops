### Local Verification & Testing Guide

#### Dependency Installation

**Backend:**

```bash
pip install -r backend/requirements.txt
```

**Frontend:**

```bash
cd frontend/ecommerce-frontend
npm install
```

### Automated Test Suites

**Backend Unit Tests**
Ensure karein ki `PYTHONPATH` context properly set hai:

```bash
PYTHONPATH=backend python -m pytest backend/tests
```

**Frontend Component Tests:**

```bash
cd frontend/ecommerce-frontend
npm test -- --watch=false
```

### Manual QA Walkthrough

#### 1. Setup & Login

Backend **(FastAPI)** aur frontend **(Angular 19)** servers start karein.

Privileged views access karne ke liye **Admin credentials** se login karein.

#### 2. Admin Orders

Sidebar mein **Admin Operations** par click karein.

* Verify karein ki layout mein saare orders ki list properly render ho rahi hai.
* Dropdown se order status update karne ka option select karein.
* Confirm karein ki status update **FSM business rules** ke according ho raha hai.

#### 3. Customer Directory

**Customers** par click karein.

Verify karein ki table mein registered users ke:

* Users
* Roles
* Status

properly display ho rahe hain.

#### 4. Reports

**Reports** par click karein.

Verify karein ki:

* **Total sales volume** properly show ho raha hai.
* Un products ki list bhi display ho rahi hai jinki `stock_quantity <= 10` hai.

#### 5. Customer Checkout Flow

Logout karein aur ek **standard customer** ke account se login karein.

**Orders** par navigate karein → ek **pending order** select karein → **"Proceed to Payment"** par click karein.

Verify karein ki simulated checkout successfully complete hone ke baad order ka status **`PROCESSING`** mein transition ho raha hai.
