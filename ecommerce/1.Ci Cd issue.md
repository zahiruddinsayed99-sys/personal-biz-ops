### 1. Create the GitHub Actions Workflow File

You need to create a new YAML file that tells GitHub how to build and test your application.

**File Path:** Create this exact folder structure at the absolute root of your project (outside of `frontend/` and `backend/`):
`.github/workflows/ci.yml`

**File Content:** Paste this into `ci.yml`:

```yaml
name: CI/CD Pipeline

# Trigger the workflow on pushes and pull requests to main and develop branches
on:
  push:
    branches: [ "main", "develop" ]
  pull_request:
    branches: [ "main", "develop" ]

jobs:
  backend-test:
    name: Backend Build & Test (FastAPI)
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4
        
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11' # Adjust to your Python version if different
          
      - name: Install Dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r backend/requirements.txt
          
      - name: Run PyTest
        run: |
          cd backend
          PYTHONPATH=. pytest tests/

  frontend-test:
    name: Frontend Build & Test (Angular)
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4
        
      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20' # Adjust to your Node version if different
          
      - name: Install Dependencies
        run: |
          cd frontend/ecommerce-frontend
          npm install
          
      - name: Build Angular App
        run: |
          cd frontend/ecommerce-frontend
          npm run build
          
      - name: Run Frontend Tests
        run: |
          cd frontend/ecommerce-frontend
          npm run test -- --watch=false

```
