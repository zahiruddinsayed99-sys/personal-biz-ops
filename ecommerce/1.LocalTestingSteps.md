Local Verification & Testing Guide

1.  **Database Migrations**:
    *   Navigate to the `backend` directory.
    *   Run `alembic upgrade head` to apply the migration creating `courses`, `course_modules`, `lessons`, `course_enrollments`, `lesson_progress`, `quizzes`, `quiz_questions`, `quiz_answers`, `quiz_attempts`, and `quiz_responses` tables.
    *   Verify the Alembic history correctly migrates using `pytest tests/test_database_migrations.py -v`.
    
2.  **API Verification**:
    *   Ensure the backend API runs (`uvicorn app.main:app`).
    *   **Authoring API**: Test that `TENANT_OWNER` can create courses via `POST /api/v1/lms/courses`. Test that `DOMAIN_MEMBER` receives an HTTP 403 Forbidden on the same route. Ensure lookup failures across tenants return `404 Not Found`.
    *   **Learner API**: Test submitting a quiz attempt `POST /api/v1/lms/quizzes/attempts`. Confirm that attempting a quiz calculating to ≥ 80% correctly returns `passed: True`, and correctly logs to the database. Confirm `POST /api/v1/lms/lessons/{id}/progress` logs lesson completion and automatically computes/transitions `CourseEnrollment` to `COMPLETED` when all modules' lessons are complete.
    
3.  **Automated E2E Tests**:
    *   From the `backend` directory, run all test validations:
        `python -m pytest tests/ -v`
    *   Verify that `test_lms_authoring.py`, `test_lms_learner.py`, and `test_database_migrations.py` completely pass along with the pre-existing suite.
