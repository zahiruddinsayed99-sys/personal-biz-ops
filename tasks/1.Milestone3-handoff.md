### Architectural Design & System Contracts

#### 1. RS256 Asymmetric Cryptosystem
- **Module**: [`security.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/security.py)
- **Key Management**:
  - `JWT_PRIVATE_KEY` and `JWT_PUBLIC_KEY` loaded from environment / PEM files via [`config.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/config.py).
  - Automated `\n` unescaping is applied to raw `.env` key strings.
  - **Dynamic Fallback**: If keys are absent in development, a temporary 2048-bit RSA key pair is dynamically generated at startup with a `UserWarning` logged.
- **Tokens & Cookies**:
  - **Access Token**: 15-minute TTL. Payload claims: `sub`, `user_id`, `email`, `roles`, `jti`, `iat`, `exp`, `type="access"`.
  - **Refresh Token**: 7-day TTL. Served strictly via HttpOnly, `SameSite=Strict`, `Secure=not settings.DEBUG` cookies.

#### 2. Stateful Redis Session Management
- **Modules**: [`session.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/session.py), [`redis.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/redis.py)
- **Key Contract Pattern**: `sess:{user_id}:{token_id}` with a 7-day TTL (604,800s).
- **Session Lifecycle**:
  - `create_session`: Writes metadata JSON (`created_at`, `ip_address`, `user_agent`) to Redis.
  - `revoke_session`: Immediately deletes `sess:{user_id}:{token_id}` on logout.
  - `revoke_all_user_sessions`: Scans and purges `sess:{user_id}:*` on password reset or account revocation.
- **Event Loop Safety**: Redis client binding detects asyncio loop context switches to prevent `RuntimeError: Event loop is closed` during parallel test runs.

#### 3. Multi-Tenant Isolation Middleware
- **Module**: [`tenant_middleware.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/tenant_middleware.py)
- **Request Pipeline Interception**:
  1. Extracts JWT from `Authorization: Bearer <token>` header or `access_token` cookie.
  2. Validates RS256 signature and checks session state in Redis (`is_session_active`).
  3. Extracts mandatory `X-Organization-Id` request header.
  4. Validates user membership in the target organization by querying `user_roles`.
- **Context Binding**:
  - Binds active tenant to Python `ContextVar` (`current_tenant_id`).
  - Binds active tenant to SQLAlchemy session query context (`db.info["tenant_id"]`).

#### 4. Cached Role-Based Access Control (RBAC) Engine
- **Module**: [`rbac.py`](file:///home/zahsay/projects/businesshub-ai/backend/app/core/rbac.py)
- **Declarative Dependency**: `RequiresPermission("crm:write")`
- **Cache Key Contract Pattern**: `org:{org_id}:usr:{user_id}:perms` with 15-minute TTL (900s).
- **Cache Eviction**: `evict_user_permissions_cache` automatically purges the permission key upon role updates or deactivation in DB.

#### 5. Standard System Error Envelopes
All security exceptions return standard JSON response bodies:

| Status Code | Error Code | Trigger Condition |
| :--- | :--- | :--- |
| `401 Unauthorized` | `ERR_AUTH_001` | Invalid, expired, blacklisted, or missing JWT / session |
| `403 Forbidden` | `ERR_TENANT_001` | Missing `X-Organization-Id` header or non-member organization access attempt |
| `403 Forbidden` | `ERR_RBAC_001` | Authenticated user lacks required permission scope |
