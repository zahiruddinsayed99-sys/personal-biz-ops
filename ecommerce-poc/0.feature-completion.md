Implements the Proof of Concept (POC) E-Commerce Application for the Indian Beauty, Cosmetics & Grooming Market. 

Key features included:
*   **Backend (`backend/main.py`)**: Python FastAPI backend with in-memory state management handling catalog delivery, customizable bundles, checkout configuration, mock Razorpay payment processing, and admin endpoints.
*   **Frontend (`frontend/`)**: Angular v16+ UI styled with Tailwind CSS, strictly implementing 6 behavioral design patterns (Contrast Effect, The IKEA Effect, Reciprocity, Goal Gradient Effect, Loss Aversion, Smart Defaults).
*   **Simulated Payments**: Custom Razorpay / UPI modal allowing users to simulate success or failure of transactions.
*   **Admin Dashboard**: Interactive admin view for monitoring and modifying orders in real-time.

Verified visually with Playwright for an end-to-end bug-free flow.
