## 3. Important technical decision: HTML only or local Python?

Aapne dashboard se images add karne aur categories manage karne ki requirement bhi rakhi hai. Is wajah se ek important distinction hai.

Recommended: Local Python + HTML dashboard

- Double-click `Start_SwingPilot.bat` to launch.
- Dashboard browser mein open hoga.
- Images, category changes, titles aur favorites reliably local files mein save honge.
- Internet ki zaroorat nahi; Python ko sirf pehli baar install karna padega.

Alternative: Pure static HTML

Basic gallery aur image viewing ke liye achha hai. Lekin local files ko copy karna, permanently manage karna aur library data save karna browser ki permissions aur storage limitations par depend karega.

Meri final recommendation: Python-powered local application with an HTML interface. Python background mein sirf local file management karega; koi cloud server ya online account required nahi hoga.

## 4. Final folder structure

`Start_SwingPilot.bat` — one-click launcher

`templates/` — dashboard pages

`static/` — CSS and JavaScript

`library/` — imported images

`catalog.db` — image details, categories and favorites

Aapki existing images ek source folder mein hain, isliye hum bulk import feature rakhenge. Application image files ko apni library mein copy karega, unhe categories assign karne dega aur original files ko delete nahi karega.

## 5. Image add karne ka workflow

1. Dashboard open karein aur Add Images par click karein.
2. Apna existing images folder select karein; multiple images ek saath import karein.
3. Application duplicate files ko identify karne ki koshish karega, taaki unnecessary copies na banen.
4. Images ko suggested ya manually selected categories assign karein.
5. Titles aur tags edit karein, phir gallery se kisi bhi image ko click karke open karein.

## 6. Coding se pehle final scope

Ye proposed Version 1 specification hai:

- Platform: Windows desktop, browser-based local application.
- Connectivity: Fully offline after setup; no cloud dependency.
- Theme: Dark/light toggle.
- Library: Bulk image import from one folder.
- Organization: Editable categories, tags, descriptions and favorites.
- Navigation: Search, filters, previous/next, zoom and full-size viewer.
- Data safety: Original images remain untouched; library metadata and image files can be backed up together.
- Launch: One-click `.bat` file; no command typing during normal use.
- Scope boundary: Ye visual reference library hoga, live trading terminal nahi. Trading signals ya broker integration is version mein nahi hoga.

Ek practical note: local Python application ke liye initial Python setup zaroori hoga. Agar aapke computer par Python pehle se installed hai, to setup aur simple ho jayega.
